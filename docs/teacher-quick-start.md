## 수업 전 준비

| 확인 항목 | 권장 준비 |
| --- | --- |
| 기기 | 태블릿, 노트북, 전자칠판 중 1가지 |
| 소리 | 전체 음량 50~70%, 조별 활동이면 이어폰 또는 낮은 스피커 음량 |
| 브라우저 | Chrome, Edge, Safari 최신 버전 |
| 시작 상태 | 페이지 새로고침 후 `음계로 맞추기`를 눌러 도레미 기준 상태 확인 |

## 40분 수업 흐름

1. **도입 5분**: “물이 많아지면 소리는 높아질까, 낮아질까?”를 먼저 예측하게 합니다.
2. **시범 5분**: 컵 1개를 골라 물 높이를 낮추고 높이며 소리 변화를 들려줍니다.
3. **탐구 15분**: 학생이 2~3개 컵의 물 높이를 바꾸고 소리 높낮이를 활동지에 기록합니다.
4. **튜닝 10분**: `도레미 튜닝 미션`에서 8/8에 가까워지도록 컵을 맞춥니다.
5. **연주 5분**: 연주 곡을 하나 선택해 계이름을 따라 치고, 물 높이와 음높이 관계를 한 문장으로 정리합니다.

## 발문 예시

- 물이 적은 컵과 많은 컵 중 어느 쪽이 더 높은 소리로 들렸나요?
- 같은 컵의 물 높이를 다시 맞추면 소리도 다시 비슷해졌나요?
- 도레미를 맞추기 어려웠던 컵은 어떤 컵이었나요?
- 실제 유리컵 실험을 한다면 조심해야 할 점은 무엇일까요?

## 수업 운영 팁

- 소리는 반드시 학생이 한 번씩 직접 들어보게 하되, 여러 기기가 동시에 큰 소리를 내지 않게 합니다.
- 키보드 사용 학생은 컵에 초점을 둔 뒤 `ArrowUp`, `ArrowDown`, `PageUp`, `PageDown`, `Home`, `End`로 물 높이를 조절할 수 있습니다.
- 수업 중간에 상태가 흐트러지면 `음계로 맞추기` 버튼으로 빠르게 기준 상태로 되돌립니다.
- 마무리에서는 “물의 양이 변하면 소리의 높낮이가 어떻게 달라지는가”를 관찰 근거와 함께 말하게 합니다.
