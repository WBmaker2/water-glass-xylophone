# 3~4학년 과학/음악 융합 수업 지도안 (2차 완성도 보강판)

## 1) 수업 한눈에 보기

- **수업명**: 찰랑찰랑 디지털 물컵 실로폰
- **학년**: 초등 3~4학년
- **교과 연계**: 과학, 음악
- **성취기준**
  - `[4과07-01]`
  - `[4음01-02]`
- **차시**: 1차시(40~50분)
- **도입-탐구-정리 흐름**
  - 도입 10~15분
  - 탐구 20~25분
  - 공유/정리 10분
- **수업 목표**
  1. 물의 높이 변화가 소리의 높낮이에 미치는 영향을 탐색한다.
  2. 직접 조절한 컵을 비교해 높이 변화와 음정 차이를 정리한다.
  3. 도레미를 맞추고 짧은 멜로디를 연주해 과학적 탐구와 음악적 규칙성을 연결한다.

## 2) 진행안

### 2-1. 도입 (10~15분)

1. 수업 질문 제시: “컵에 물을 더 넣으면 소리가 어떻게 바뀌고, 왜 그럴까요?”
2. 앱 화면에서 기본 컵 8개를 보여주고, 물 높이 조절 버튼(또는 슬라이더) 사용법을 빠르게 데모한다.
3. 학생 예측을 1분 동안 기록한다(개인 활동지 1단계).
4. 소리 실험 안전 규칙 1회 공지 후 탐구로 넘어간다.

### 2-2. 탐구 (20~25분)

1. **물 높이 조절 실험(8분)**
   - 각 그룹/개인이 2~3개 컵으로 시작점 세팅.
   - 물 높이를 올리고 내렸을 때 소리 변화를 즉시 듣고 기록.
2. **소리 비교 기록(7~8분)**
  - 기준 소리(이전 상태)와 바뀐 상태를 서로 비교해 높낮이 높음/낮음 판단.
3. **도레미 튜닝(5~6분)**
  - 앱의 도레미(도 레 미) 순서를 확인하며 각 컵의 반응을 맞춰 본다.
4. **짧은 연주(4~5분)**
  - 미션 곡(예: “도도솔솔라”)을 3회 이상 반복 연주해 소리 일관성 점검.

### 2-3. 공유/정리 (10분)

1. 각 조가 “어떤 컵에서 도레미가 가장 또렷했는지” 1개 컵씩 공유.
2. 활동지 마지막 정리 질문으로 결론 정리(개인 발표 1문장).
3. 교사는 물 높이(진동 조건 변화)와 소리 높낮이(진동 변화 반응)의 관계를 교차 정리.

## 3) 교사용 발문 예시

- 물이 많이 차면 소리가 높아지나요? 낮아지나요? 근거는 무엇이죠?
- 지금 소리가 변한 이유를 입으로 설명해 볼까요? (컵의 진동·공명·질량의 변화)
- 같은 높이를 더 크게 만들려면 “물 높이”를 어떻게 조절해야 할까요?
- 도레미를 맞출 때 가장 헷갈린 점은 무엇이었나요?
- 연주에서 한 번도 같은 소리가 안 나는 구간이 있었나요? 왜 그럴까요?
- 실험 기록이 연주 정확도에 어떻게 도왔나요?

## 4) 안전 및 기기 운영 팁

- 이어폰/스피커 음량은 과도하게 높이지 않고, 동시 연주 구간에서 볼륨을 70% 이하로 유지한다.
- 브라우저 탭은 한 개로 유지하고, 수업 시작 전 페이지 새로고침으로 상태를 초기화한다.
- 키보드 조작이 가능한 기기에서는 물 높이 조절 시 방향키가 반응하는지 먼저 확인한다.
- 모바일에서는 화면 가로 기준으로 배치가 바뀔 수 있으니 수업 전에 오버플로우(화면 밖 요소) 유무를 확인한다.
- 반응형 화면에서 버튼 크기/간격을 확인해 소근육 발달 단계에 맞게 클릭 성공률을 높인다.

## 5) 평가 관찰 포인트 (교사 체크리스트)

- 물 높이 조절 전후를 말로 예측하고 다시 검증하는지
- 소리 높낮이 변화를 최소 1개 기준점으로 비교해 기록하는지
- 도레미 음정 맞추기에서 오차를 스스로 수정하는지
- 활동지에 실험 결과(높음/낮음/비슷함)를 일관되게 남기는지
- 짧은 연주에서 시작-끝 음의 일관성 유지(리듬보다 음정 중심)
- 협력 활동에서 역할 분담(조작·기록·발표)을 지키는지

## 6) 수업 반성 포인트(교사 기록)

1. 어느 단계에서 학생의 오개념이 많이 드러났는지
2. 앱 조작 난이도에서 개선이 필요한 부분(조절 감도/피드백 문구/기기 반응 지연)
3. 다음 수업에서 보완할 실험 질문 또는 보충 활동
